# SIPANDU ODHIV — Catatan Rilis v5.0.5

Tanggal: 9 November 2026

## Koreksi pemeriksaan unduhan arsip dokumen
- Tipe parameter dokumen unduhan kini menyertakan ukuran dan MIME type yang tersimpan pada metadata Firestore.
- Verifikasi ukuran dan tipe file hasil unduh menggunakan nilai metadata tersebut secara langsung sehingga file terverifikasi tidak salah ditolak.
- Tidak mengubah data dokumen, izin akses, atau konfigurasi layanan.

## Nomor versi
Versi web, PWA, dan Android disinkronkan ke **5.0.5**.
